# TaskFlow — Kanban-менеджер задач із колаборацією в реальному часі

> Повнофункціональний веб-застосунок для командного управління задачами.  
> Фронтенд задеплоєно на **Vercel**, бекенд на **Render.com**, БД на **MongoDB Atlas** — доступно 24/7.

🔗 **Live demo:** [react-course-work-mu.vercel.app](https://react-course-work-mu.vercel.app)

---

## Про проєкт

TaskFlow вирішує проблему організації командної роботи над задачами. Це Kanban-дошка з миттєвою синхронізацією між усіма учасниками через WebSockets — зміни відображаються в реальному часі без перезавантаження сторінки.

**Деплой:** Vercel (frontend) · Render.com (backend) · MongoDB Atlas (database)

## Функціонал

### Kanban-дошка
- Три колонки: **To Do → In Progress → Done**
- Drag & Drop між колонками та всередині колонки
- Пріоритети задач (Low / Medium / High) з кольоровою підсвіткою
- Дедлайни з автоматичним підсвічуванням прострочених задач
- Мітки та теги для категоризації
- Розширений пошук та фільтри

### Колаборація в реальному часі (Socket.IO)
- Миттєва синхронізація нових задач та змін для всіх учасників
- Drag & Drop відображається у всіх користувачів дошки
- Онлайн-індикатори — видно хто зараз працює на дошці
- Спливаючі сповіщення про дії учасників

### Дошки та команди
- До 3 дошок на одного користувача
- До 5 учасників на одну дошку
- Запрошення через унікальний код
- Аватарки учасників з онлайн-статусом

### Автентифікація
- Безпечна реєстрація з валідацією пароля (bcrypt)
- JWT токени з терміном дії 7 днів
- Відновлення пароля через секретне питання
- Редагування профілю (нік, аватарка, пароль)

### Статистика
- Кругова діаграма по статусах задач
- Стовпчаста діаграма по пріоритетах
- Топ-5 міток та тегів
- Список прострочених задач

## Локальний запуск

### Вимоги
- Node.js 18+
- MongoDB (локальний або Atlas)

### Frontend
```bash
cd Task-Manager
npm install
npm start
```

### Backend
```bash
# (якщо бекенд у окремому репо)
npm install
# Створи .env файл:
# MONGO_URI=your_mongodb_uri
# JWT_SECRET=your_secret
# PORT=5000
npm start
```
